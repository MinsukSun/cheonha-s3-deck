# 천하결전 S3 덱 관리

삼국지: 천하결전 **한국 서버 시즌3(업주산하)** 추천 덱을 보유 무장·전법 기준으로 관리하는 정적 웹사이트입니다. 설치할 것 없이 HTML·JS만으로 동작합니다.

## 실행

```bash
python3 -m http.server 8765   # 이 폴더에서 실행
```

브라우저에서 http://localhost:8765 를 엽니다. `index.html`을 더블클릭해서 열어도 됩니다.

## 기능

| 탭 | 내용 |
|---|---|
| 추천 덱 | 시즌3 티어덱·변칙덱·공존덱·커뮤니티 덱. 선택한 계정 기준으로 **구성 가능 / 돌파 부족 / 전법 부족 / 무장 부족**을 표시하고, 하나만 더 있으면 열리는 전법·무장을 알려줍니다 |
| 보유 관리 | 계정별로 무장(돌파 0~5)과 전법(1개 / 영본 포함 2개)을 칩을 눌러 선택합니다. 이름을 붙여넣어 한 번에 입력하거나 다른 계정에서 복사할 수 있습니다 |
| 계정별 편성 | 덕구·부계정 2개 계정의 부대 편성을 나란히 봅니다. **자동 추천 편성**은 무장이 겹치지 않고 전법 수량을 넘지 않게 티어가 높은 덱을 고릅니다 |
| 공존덱 프리셋 | 시트의 2~5 공존덱 묶음을 계정마다 동시에 구성할 수 있는지 확인하고, 바로 편성에 적용합니다 |
| 데이터·설정 | 구글 시트 링크 연동(**지금 업데이트**), 내 덱 직접 추가, CSV 내보내기, 백업·복원 |

## 데이터 업데이트

- 사이트 안에서 **데이터·설정 → 지금 업데이트**를 누르면 구글 시트에서 최신 내용을 바로 받아옵니다. 받은 내용은 그 브라우저에 저장됩니다.
- 내 시트를 쓰려면 예시 시트를 **사본 만들기**로 복사하고, *링크가 있는 모든 사용자: 뷰어*로 공유한 뒤 링크를 붙여넣으면 됩니다.
- 한 줄에 덱 하나씩 적는 형식도 지원합니다. 탭 형식을 `내 시트`로 지정하고, 첫 줄에 `덱이름, 티어, 분류, 진형, 무장1, 무장1전법1, 무장1전법2, 무장1병종, 무장1병법, 무장2…, 비고` 열을 둡니다.
- 사이트에 기본으로 들어 있는 데이터(`data/sheet-cache.js`)를 새로 만들려면:

```bash
python3 scripts/sync_sheet.py
```

## 캡처로 보유 입력

**보유 관리** 탭에서 게임 화면 캡처를 붙여넣으면 무장·전법 이름과 돌·품을 읽어 보유 목록을 채웁니다.

1. 게임(Windows)에서 무장 목록이나 전법 창을 **Win+Shift+S**로 캡처합니다.
2. 사이트 **보유 관리** 화면에서 **Ctrl+V**를 누릅니다. 이미지 파일을 끌어놓거나 **파일 고르기**로 열어도 됩니다.
3. 찾은 무장·전법이 확인 목록으로 나옵니다. 틀린 것은 체크를 풀고, 돌·품, SP/연의 여부, 전법 개수(영본)를 고친 뒤 **보유로 저장**을 누릅니다.

- 글자 인식은 [Tesseract.js](https://github.com/naptha/tesseract.js)로 **브라우저 안에서** 합니다. 이미지는 어디에도 올라가지 않습니다. 처음 한 번만 인식 도구와 한국어 데이터(약 2MB)를 내려받습니다.
- 읽은 글자를 사이트의 무장·전법 이름과 맞춰 봅니다. 4글자 이상은 한 글자 틀려도 찾고("비슷" 표시), 짧은 이름은 정확히 일치할 때만 찾습니다.
- **돌은 그림으로 읽습니다** (게임 Windows 버전 캡처 기준):
  - 무장 카드: 이름("50 조조") 바로 위 빨강·주황 돌 아이콘 개수를 셉니다.
  - 전법 목록: 레벨 숫자 둘레의 고리가 5칸(72°씩, 위에서 시계 방향)으로 나뉘어 금색으로 채워진 칸 수를 셉니다.
  - 오른쪽 큰 전법 카드: 제목 위 빨간 돌 아이콘을 셉니다.
  - 샘플 캡처 8장에서 알려주신 정답(조조 1, 주태 2, 대교 3, 황개 2 / 청천벽력 3, 청풍 질주 2, 철기병 돌격 1, 예리한 판단 0, 수중전 4, 측면 공격 5)과 모두 맞았습니다. 고리를 못 찾은 줄은 확인 목록에 "읽음" 표시 없이 나오니 직접 고르세요.
- 전법 화면에서는 전법 아래 소유 무장 이름을, 무장 화면에서는 우연히 잡힌 전법 이름을 무시합니다.
- 체크한 항목만 저장하고, 목록에 없는 기존 보유는 건드리지 않습니다. 공유 저장소에 연결돼 있으면 저장 후 자동으로 공유됩니다.

## 5부대 편성 (메인 3 + 보조 2)

**계정별 편성 → 자동 추천 편성**은 부대 수(기본 5)를 메인(기본 3)과 보조로 나눠 채웁니다.

1. 🔒 **고정한 부대**는 무장을 그대로 두고, 전법만 지금 보유 기준으로 다시 고릅니다. 없는 전법은 대체 전법으로 바꾸고, 대체도 없으면 "○○ 없음"으로 비워 둡니다.
2. **메인**: 티어가 높은 덱부터 고릅니다. 대체 무장은 1명까지 씁니다.
3. **보조**: 남은 무장·전법으로 고릅니다. 대체 무장은 2명까지 씁니다.
4. 그래도 빈 자리는 **남은 무장 부대**로 채웁니다. 남은 무장 3명(전열 1명 우선)과, 각자 덱에서 자주 쓰는 보유 전법을 넣습니다.
5. 고정하지 않은 자리는 점수 순으로 다시 배치해서, 실제 덱이 메인을 먼저 차지합니다.

- 무장(같은 인물의 기본·연의 포함)과 전법 수량(영본 포함)은 부대끼리 겹치지 않습니다.
- 메인 덱이 정해지면 🔒로 고정해 두세요. 이후 보유를 업데이트하고 다시 자동 편성하면, 메인 무장은 유지하고 전법과 보조 부대만 바뀝니다.
- **연의 선택**: 원소/연의 원소처럼 한쪽을 고르면 반대쪽은 미보유로 봅니다. 미정이면 둘 다 후보지만 한 부대에만 나옵니다.
- **뽑기 추천**: 아직 없는 무장을 한 명씩 0돌로 넣어 보고 5부대 편성 점수(메인 ×1, 보조 ×0.6)가 많이 오르는 순서로 보여줍니다. 어느 부대에 들어가는지도 함께 나옵니다.

## 대체 무장·전법 추천

무장이나 전법이 없는 덱은 카드에 **보유 중인 대체 후보**(최대 3개)를 보여줍니다. 후보에 마우스를 올리면 근거가 보입니다.

- **대체 무장 점수**
  - 실제 교체 사례(가장 높음): 다른 두 무장이 같은 덱끼리 남은 자리의 무장, 시트의 `손권 / 대교` 같은 대체안
  - 고유전법 특성(보조·병기·책략·치유·방어·문무)과 유형(지휘·액티브·패시브·추격), 병종, 위치(전열·균형·후열), 진영
  - 고유전법 효과 태그의 겹침
- **대체 전법 점수**
  - 실제 교체 사례: 시트의 `결사의 다짐/기선제압` 같은 대체안, 같은 무장 조합에서 같은 자리 전법이 다른 덱
  - 같은 유형(지휘·액티브·패시브·추격)과 특성(병기·책략·보조…)
  - 효과 태그(병기피해·책략피해·회복·피해감소·적약화·제어·상태부여·전체/2명/단일 등)의 겹침. 태그는 [삼천 데이터 전법 표](https://three-kingdoms-data-browser.vercel.app/info/)의 효과 문장에서 뽑았습니다(`data/sim-data.js`).
- **계정별 편성 → 대체 허용**(기본 켜짐): 무장 2명·전법 3개까지 없는 덱은 대체한 구성도 자동 추천 후보에 넣습니다. 대체 무장 1명당 −2.5점, 전법 1개당 −0.8점을 빼서 원래 덱이 있으면 원래 덱을 우선합니다. 대체하지 않은 자리의 돌 조건은 그대로 지킵니다. 편성에는 `덱이름 (대체)`로 나옵니다.
- **직업은 반영하지 않습니다.** 조사해 보니 6개 직업(병참·청낭·천공·진군·기좌·신행)은 전투 속 능력치·전법·병종·치유율을 바꾸지 않았습니다. 사망률·예비병·공성치·이동 속도 같은 맵 효과만 있어서 대체 무장 선택과는 관계가 없습니다(출처: [삼천 데이터 직업표](https://three-kingdoms-data-browser.vercel.app/info/?sheet=jobs)). 다만 1·2·4·5단계 숙련 특성의 효과는 공개된 자료가 없어 확인하지 못했습니다.

## 돌파 수준 (명함 / 중간돌 / 고돌)

추천은 무장 돌파 기준으로도 나뉩니다. 전법은 보유 여부만 봅니다.

- **계정 돌파 수준**: 덱에 쓰이는 보유 무장의 평균 돌로 자동 판단합니다. 평균 1돌 미만 = 명함, 3돌 미만 = 중간돌, 그 이상 = 고돌입니다. 추천 덱·보유 관리·계정별 편성의 **돌파 수준**에서 직접 고를 수도 있습니다.
- **덱 돌파 기준**: 시트·사이트 문구로 정합니다. "고돌파용", "높은 돌파 권장", "고승품" → **고돌 덱**. "저돌파용", "명함", "낮은 돌파도 가능" → **명함·저돌 가능**. "모든 돌파용"이거나 문구가 없으면 기준 없음.
- 덱 카드에 태그가 붙습니다: 내 수준에 맞으면 ✓, 고돌 덱인데 내 수준이 낮으면 ⚠. 마우스를 올리면 그 덱 무장의 내 평균 돌이 보입니다. 공존덱 프리셋도 계정별로 "수준 맞음 ✓ / 고돌용 ⚠"을 표시합니다.
- 자동 추천 편성은 맞는 덱에 가산점(+0.5), 고돌 권장인데 수준이 낮은 덱에 감점(−1.5)을 줍니다. "마초 3돌 이상"처럼 덱에 적힌 무장별 돌 조건은 지금처럼 따로 판정합니다.

## 돌파·승품 조건

덱 설명·비고의 `마초 3돌 이상`, `마운록 4돌 2품 이상` 같은 문구에서 무장별 최소 돌파·승품을 읽어 판정과 자동 편성에 반영합니다. 조건을 채우지 못한 덱은 **돌파·품 부족**으로 표시됩니다.

- 문구에 처음 나오는 조건이 일반 조건입니다. 바로 뒤에 `시골섭에는 3돌 1품`처럼 완화 조건이 있으면 따로 읽어 둡니다.
- 계정마다 **서버: 일반 조건 / 시골섭 완화**를 고를 수 있습니다(추천 덱·보유 관리·계정별 편성 탭). 시골섭 완화를 고르면 완화 조건이 있는 덱은 그 조건으로, 없는 덱은 일반 조건으로 판정합니다. 지금 시트에서 완화 조건이 있는 덱은 공마마(마운록 3돌 1품)와 조순이(왕이 2돌 1품)입니다.
- 완화 조건도 같은 무장 3명 조합의 다른 탭 덱에 적힌 값을 따르지만, 그 덱의 일반 조건보다 엄격해지지 않게 맞춥니다.
- 설명에 조건이 없는 덱은 다른 탭에 있는 같은 무장 3명 조합 덱의 조건을 따릅니다. 돌파와 품은 각각 가장 낮은 값을 씁니다.
- 보유 관리 무장 탭의 **돌파** 모드는 칩을 누를 때마다 미보유 → 0돌 → … → 5돌 → 미보유로 바뀌고, **품** 모드는 품을 0→5→0으로 바꿉니다. 전법 탭은 **보유** 모드(보유/해제)와 **영본 개수** 모드(1개 ↔ 2개)입니다. 돌파·승품 모두 최대 5단계입니다. 근거는 [17173 기사(2025-02-22)](https://news.17173.com/content/02222025/143601484.shtml)의 "升品也是有5红"와 커뮤니티의 "총 5품" 설명이고, 바뀌면 `app.js`의 `MAX_STARS`, `MAX_GRADE`만 고치면 됩니다. 붙여넣기 입력에서는 `마운록:4:2`(4돌 2품)처럼 씁니다. 입력하지 않은 무장은 0돌 0품으로 봅니다.
- 내 시트에서는 `돌파조건` 열(예: `마초 3돌, 마운록 4돌 2품 (시골섭 3돌 1품)`)로, 내 덱에서는 무장별 "필요 돌파"·"필요 승품"으로 조건을 정합니다.

## 전법 유형 (`data/tactic-types.js`)

보유 관리의 전법은 지휘·액티브·패시브·추격으로 나눠 보여줍니다. 유형은 [삼천 데이터 전법 표](https://three-kingdoms-data-browser.vercel.app/info/)(S1~S3, 105개)에서 가져왔습니다. 그 표에 없는 4개는 중국 서버 자료([sgmdtx.com](https://www.sgmdtx.com/zf/%E8%BF%90%E6%99%BA%E9%93%BA%E8%B0%8B), [17173](https://news.17173.com/content/12222024/005704258.shtml))로 채웠습니다: 지략운용(运智铺谋) 패시브, 공성계(空城计) 지휘, 사방의 매복(十面埋伏) 액티브, 경천위지(经天纬地) 액티브.

## 접속 인증 키

처음 열면 인증 키를 묻습니다(현재 키: `1234`). "이 브라우저에서 기억하기"를 켜 두면 다음부터는 묻지 않고, **데이터·설정 → 다시 잠그기**로 다시 잠글 수 있습니다.

- 정적 사이트라 화면만 가리는 수준입니다. 주소를 아는 사람은 `app.js`, `data/*.js` 파일을 직접 열어 덱 데이터를 볼 수 있습니다. 보유 정보·편성은 각자 브라우저에만 있어서 다른 사람에게 보이지 않습니다.
- 키를 바꾸려면 사이트를 연 브라우저 콘솔에서 `__tk3hash('새키')`를 실행하고, 결과를 `app.js`의 `AUTH_HASH`에 넣습니다.

|---|---|
| 덕구·부계정 보유 무장·전법, 편성, 내 덱, 시트 설정 | **공유 저장소**: 이 GitHub 저장소 `data` 브랜치의 `shared-state.json` (+ 브라우저에 사본) |
| 보던 탭·필터·선택한 계정, 인증 기억, GitHub 토큰 | 각 브라우저 (localStorage) |

### 공유 비밀번호 (브라우저마다 토큰을 넣지 않기)

토큰을 **공유 비밀번호로 암호화**해 저장소(`data` 브랜치 `auth.json`)에 올려 두면, 어느 브라우저에서든 비밀번호만으로 저장할 수 있습니다.

1. 한 번만 설정: 토큰이 연결된 브라우저에서 **데이터·설정 → 공유 비밀번호**에 비밀번호(8자 이상)를 두 번 넣고 **비밀번호로 잠가 올리기**를 누릅니다.
2. 다른 브라우저: 입장 화면에 **공유 비밀번호**를 넣으면 보기와 저장이 모두 됩니다. 이미 `1234`로 들어와 있다면 **데이터·설정 → 공유 비밀번호 → 저장 권한 받기**를 씁니다.
3. 입장 화면에 `1234`를 넣으면 지금처럼 보기 전용으로 열립니다.

- 암호화 방식은 AES-GCM 256, 비밀번호 키 변환은 PBKDF2-SHA256 31만 회입니다. 암호문은 공개 저장소에 있으니 **추측하기 어렵고 다른 곳에 안 쓰는 비밀번호**를 쓰세요. 비밀번호가 새면 토큰을 GitHub에서 폐기하고 새로 만든 뒤 다시 올리면 됩니다.
- 토큰은 이 저장소(`cheonha-s3-deck`)의 Contents 권한만 있는 Fine-grained token을 쓰고, 만료 기한을 두는 것을 권장합니다.

### 공유 저장소 사용법

1. 처음 쓰는 기기에서 **데이터·설정 → 공유 저장소**를 엽니다. 읽기는 설정 없이 바로 되고, 화면 위 `☁` 표시에 상태가 나옵니다.
2. 저장까지 하려면 GitHub 토큰을 한 번 넣습니다. [Fine-grained token 만들기](https://github.com/settings/personal-access-tokens/new)에서 다음처럼 설정하고 **설정 저장 후 연결**을 누릅니다.
   - Repository access: **Only select repositories** → `cheonha-s3-deck`
   - Permissions: **Contents → Read and write**
3. 이후 보유·편성을 바꾸면 1.5초 뒤 자동 저장됩니다. 다른 기기는 창으로 돌아올 때와 1분마다(토큰이 있을 때) 최신 내용을 받습니다.

- 두 기기가 동시에 저장하면, 서버의 최신본에 **내가 바꾼 계정만** 덮어써서 다시 저장합니다. 그래서 덕구와 부계정을 서로 다른 사람이 고쳐도 둘 다 남습니다. 같은 계정을 동시에 고치면 나중에 저장한 쪽이 이깁니다.
- 처음 연결할 때 이 브라우저에만 있던 데이터는 공유 내용으로 바뀝니다. 이전 내용은 브라우저에 따로 보관됩니다. 이 브라우저 내용을 공유본으로 쓰려면 **이 브라우저 내용 올리기**를 누르세요.
- 저장할 때마다 `data` 브랜치에 커밋이 하나씩 쌓입니다. 사이트(`main`)는 다시 빌드되지 않고, 예전 상태는 커밋 기록에서 되돌릴 수 있습니다.
- 저장소가 공개라서 공유 파일 내용(보유 무장·편성)도 공개됩니다. 토큰은 공유하지 말고 기기마다 각자 넣으세요.

## 추가 조사 덱 (`data/research-decks.js`)

엑셀 시트 외 자료에서 무장과 전법이 모두 확인되는 덱 39개를 **추가 조사**로 넣었습니다. 추천 덱 탭의 출처 선택에서 따로 볼 수 있고, 자동 편성에도 쓰입니다. 같은 티어 표기라도 시트 덱보다 한 단계 낮게 정렬됩니다.

- 한국 S3 **업주산하**는 중국 서버의 **业铸山河** 시나리오(중국 S4·S5 W6)에 해당합니다. 중국·대만 자료에서 "S3"를 찾으면 다른 시즌이 나오니 주의하세요.
- [천하결전 덱 빌더 v7.0](https://cheonha-deck-lab.troyboy86.chatgpt.site/)의 **문정 1** 보기는 업주산하 덱 53개입니다. 그중 시트에 없는 조합·전법 변형 16개를 넣었습니다.
- [삼천 데이터 · 통합 S3 (중국 기준 S4·S5)](https://three-kingdoms-data-browser.vercel.app/season-formations/?season=3)의 추천 조합 23개를 넣었습니다(중복 1개 제외). 일부는 대만 유튜브(三國謀定天下義子 「S3 最強陣容一覽」), Bilibili, 18183 자료를 옮긴 것입니다.
- 삼천 데이터는 일부 전법을 한자음으로 적습니다. 같은 전법으로 판단되는 것은 합쳤습니다: 절충어모→침략방어, 세근벌수→신체개조, 좌예절봉→기선제압, 운지포모→지략운용, 십면매복→사방의 매복. 모두 중국 业铸山河 시즌의 신규 전법(折冲御侮·洗筋伐髓·挫锐折锋·运智铺谋·十面埋伏)이고, 한국 이름은 예시 시트의 S3 카드팩 추천 목록에 있습니다. 보유 관리의 전법 칩에 `*` 표시가 있고, 마우스를 올리면 다른 표기가 보입니다.
